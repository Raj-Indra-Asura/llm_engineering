# GridLens Learning Log

- **Week 1**: provider abstraction and API design show up in the FastAPI entry points, secrets management comes from `.env` settings, and retry-ready patterns are preserved by keeping side effects isolated from the engine.
- **Week 2**: tool-calling ideas map to the FastAPI endpoints, Gradio provides the operator interface, and comparison views maintain lightweight scenario state.
- **Week 3**: structured outputs use Pydantic models, fixture loading demonstrates deterministic data processing, and explanation routing switches between offline and optional LLM behavior.
- **Week 4**: generated-code safety is reflected by avoiding `exec()`, subprocess work is limited to explicit CLI commands, and evaluation-ready benchmarking patterns appear in tests and the retrieval harness.
- **Week 5**: the RAG pipeline covers chunking, embeddings, Chroma persistence, metadata, citations, and retrieval quality evaluation metrics.
